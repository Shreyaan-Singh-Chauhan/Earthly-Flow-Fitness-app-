# Earthly Flow — Fitness App

A small project containing a chat app and static site assets.

## Quick Start

- Install dependencies (if any):

```bash
npm install
```

- Serve static files locally on port 3000:

```bash
npx serve -l 3000
```

- Alternatively run the Node server (if used):

```bash
node server.js
```

## Chat App — Notes

- Clear chat (Wi‑Fi method):

```
http://172.16.44.240:8000/clear-chat
```

## Useful Network Commands

- Get the local IP for the main Wi‑Fi interface (macOS):

```bash
ipconfig getifaddr en0
```
